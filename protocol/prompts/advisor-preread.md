# 老师 / 秘书 AI 预读反馈提示词（`advisor-review`）

> 兼容 v1.1 单文件周报（`report.md`）与双文件周报（`evidence.md` + `judgment.md`）。

## 单名学生预读提示词

阅读这名学生的本周周报材料（`report.md` 或 `evidence.md`+`judgment.md`）与 `meta.yaml`，严格按以下 5 项输出：

1. **3 行摘要**：本周实际做了什么、证据是否充分、下一步是否清楚。
2. **证据与结论核查**：关键论断是否有实验日志、代码 commit 或数据路径支撑（标注`有支持`/`部分支持`/`无支持`），以及是否有明确失败尝试与边界说明。
3. **缺口与未回答问题**：指出材料中缺少但科研闭环必须回答的问题（如缺强基线、未设停止条件、阻塞原因不清）。
4. **最值得讨论的问题（最多 3 个，按重要性排序）**：写成具体问题，不下武断结论。
5. **建议路由与理由**：`不需要开会` / `小组讨论` / `1:1` / `周四深度/研究决策` / `周六产品评审` 五选一并说明理由。

### 输出纪律
- 每条意见指明针对学生文档的具体章节。
- 不确定处标明 `[不确定]`；**不写表扬和客套话**。

## 全队汇总附加输出

读完全部学生后，另外输出：
1. **跨课题重复、冲突与共同阻塞**。
2. **本周需要老师关注的排序名单**（按紧急程度排序，每人一句理由）。
3. **周二路由时段与周四讨论建议议程**。
