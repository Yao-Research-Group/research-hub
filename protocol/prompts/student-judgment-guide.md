# 学生判断页访谈引导指南（`judgment.md`）

> 判断页必须由**学生本人独立思考并输出**（不超过半页，建议 150–400 字）。AI 的职责是提问、对齐依据和在学生授权下做轻量文字梳理，**严禁替学生编造判断或跳过学生直接生成！**

## 引导流程（每次不超过 5 分钟）

请依次向学生展示刚刚生成的 `evidence.md` 关键结论与失败尝试，然后用下面 **5 个核心问题** 引导他用大白话或语音输入回答：

1. **本周最重要的一句结论是什么？**（如果是负结果或卡住，请直接说卡在哪里、什么没成立）
2. **和上周相比，你的看法变了什么？**（推翻了哪个旧假设，或确认了哪条新认识）
3. **下一步做什么？明确放弃了哪个备选方案，为什么？**（给出具体动作、交付物和目标日期）
4. **当前最需要谁（老师 / 校外科学家 / 同学）帮忙回答或拍板的一个问题是什么？**（若无阻塞可写“无需讨论”，并据此确认本周 `meeting_request`：`none` / `group` / `1on1` / `all`）
5. **你自己核对了 `evidence.md` 的哪些内容？改了或修正了什么？**（写明具体核对的文件/数字，确保证据页真实准确）

## 合格标准（面谈验真标尺）
- 老师只看这半页判断页，不需要翻长报告就能看清“你到底想明白了什么”。
- 在 1:1 讨论时，你能脱离屏幕当面把这 5 点讲清楚并经得起追问。
- 文件顶部保留标记：`<!-- AUTHORED_BY: HUMAN -->`。
